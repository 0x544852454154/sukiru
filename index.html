03 / AboutWhat Kurisu does

Stops a nukebefore it spreads.

Kurisu watches your server’s audit log, punishes whoever is destroying it, and puts back what they removed. Every panel is a Discord Components V2 card, with grey buttons and red icons only.

Antinuke with 28 modulesChannels, roles, bans, kicks, webhooks, bots, mentions, permissions, vanity URL and more. Each module has its own limit, time window and punishment.
Nuke GuardCounts destructive actions across all modules. Three in 10 seconds gets the executor kicked, even when each module stays under its own limit.
24-hour nuke watchA kicked executor is banned on sight if they act, send a message or rejoin within 24 hours. The watch survives restarts.
Raid protectionFour levels (normal, elevated, high, lockdown) that react to join speed and new accounts. Lockdown raises verification, blocks sending and pauses invites.
Whitelist for users and rolesFour levels with per-module scopes. Administrator permission alone gives no immunity.
RecoveryRestores deleted channels and roles, reverts changes, and removes rogue webhooks, bots and invites.
ModerationBans, kicks, timeouts, warnings, cases, purge, locks and slowmode, with full case history.
Slash and prefix commandsEvery command also works as a text command. The default prefix is ! and each server can change it.
04 / DocsSetup and reference

Documentation

Set up Kurisu

  • Add the bot with the button at the top of the page.
  • Drag its role near the top of your role list. Discord’s hierarchy decides whether Kurisu can punish, strip roles or restore anything.
  • Run /security to open the Security Center, then Diagnostics to check permissions, audit-log access and log channels.

Permissions Kurisu needs

The invite link requests the permissions Kurisu uses. The important ones are View Audit Log, Manage Roles, Manage Channels, Manage Webhooks, Ban Members, Kick Members, Moderate Members, Manage Guild and Manage Messages.

How antinuke works

  • Kurisu reads audit log entries and ignores entries without an executor.
  • Each module counts actions in a sliding window per executor.
  • Past the limit, Kurisu applies the punishment (strip, quarantine, timeout, kick or ban) and reverts the damage.
  • Two incidents in 24 hours escalate to a ban by default. Set it to 0 to turn escalation off.

Who is exempt

The server owner, bot owners and Kurisu itself are always exempt. Everyone else needs a whitelist entry.

  • trusted_admin Trusted Administrator
  • trusted_mod Trusted Moderator
  • bypass Security Bypass
  • bot Trusted Bot

Raid protection

By default 5 joins in 10 seconds raises the level to elevated, 10 to high and 20 to lockdown. Accounts younger than 7 days count as new. Lockdown lasts 15 minutes. Kurisu never mass-bans during a raid. Use /raid lockdown and /raid unlock to control it manually.

Prefix commands

Type the prefix before any command, for example !ban @member spam or !timeout @member 10m spam. Change it with /prefix. Text commands use the same permission and hierarchy checks as slash commands.

Logging

Set a channel per log type with /logs set. Types: antinuke, raid, moderation, member, message, channel, role, voice and config. Message logs never include message content.

What Discord does not allow

  • Messages in a deleted channel cannot be recovered.
  • Restored channels and roles get new IDs.
  • Members of a deleted role are not reassigned.
  • Server icon, banner and vanity URL cannot be restored.
